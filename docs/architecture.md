# Architecture & Concrete Data Structures

This document is the authoritative blueprint for `grus-eda`. Implementation agents must use the exact crate layout, ID types, and Structure-of-Arrays (SoA) / Compressed-Sparse-Row (CSR) structs defined here.

---

## 1. Scope and Core Principles

`grus-eda` is a fast preflight estimation toolkit for the SkyWater `sky130_fd_sc_hd` PDK. It answers architectural exploration questions—routing congestion, placement density, and static timing—in seconds on a laptop for designs up to ~100k cells, leaving sign-off, detailed routing, DRC, and LVS to OpenROAD, OpenSTA, Magic, and KLayout.

1. **Agreement before speed**: A stage is complete only when its numbers agree with OpenROAD or OpenSTA on the same inputs within the thresholds in `README.md`. Parallelization (`rayon`), SIMD, `Accelerate`, and Metal come only after the baseline CPU implementation matches the reference tool.
2. **Decoupled stages**: Every stage reads and writes standard interchange files (`LEF`, `DEF`, `Liberty`, `Yosys JSON` / gate-level `Verilog`, `SPEF`). Any stage can consume intermediate outputs generated by OpenROAD (such as an OpenROAD-placed `DEF`) or hand its output back to OpenROAD.
3. **Hybrid `i32` (DBU) + `f32` (arrays) + `f64` (scalar reductions)**:
   Our numeric types match the internal representations of the reference tools themselves—OpenDB (`int32` DBU), OpenSTA (`typedef float Delay`), and RePlAce / DREAMPlace (`float` arrays)—while avoiding `f32` reduction drift and exponential overflow:

   | Data Category | Rust Type | Rationale |
   |---|---|---|
   | Physical dimensions, pin offsets, row/site grids, legalized coordinates (LEF/DEF) | `i32` (DBU) | Matches OpenROAD's OpenDB (`1 DBU = 1 nm` in `sky130hd`). Eliminates floating-point rounding bugs (`0.9999999` vs. `1.0`) when checking cell abutment and site alignment. |
   | Total legalized HPWL sum across all nets | `i64` (DBU) | Prevents 32-bit integer overflow when summing DBU wirelengths across 100k+ nets. |
   | STA delays, slews, arrival/required times, pin/wire capacitances, NLDM tables | `f32` | Matches OpenSTA's internal `typedef float Delay;` (`~1 fs` precision over a `10 ns` clock period) and halves memory bandwidth. |
   | E2 placement coordinates, density grids, 2D DCT/FFT, and wirelength gradients | `f32` (`Vec<f32>`) | Matches RePlAce and DREAMPlace (`~1 nm` resolution across a `10 mm` die) and runs at full throughput on ARM NEON SIMD (4 lanes) and Apple Silicon Metal GPUs. |
   | E2 scalar reductions (total WA wirelength, $L_1$/$L_2$ norms, Barzilai-Borwein dot products) | `f64` (scalar accumulator) | Summing 100k+ `f32` elements in `f32` loses low-order mantissa bits and destabilizes Nesterov step sizes $\alpha_k$. Vectors stay `f32`, while `.map(\|&x\| x as f64).sum::<f64>()` (or tree/Kahan summation on GPU) preserves full accuracy at zero memory cost. |
   | E1 GCell routing demand & track supply | `f32` | Supports fractional demand in probabilistic/RISA routing while fitting in cache. |

## 2. Stage Ordering (Value-First Pipeline)

```
  [Yosys JSON / Verilog] + [LEF / Liberty] + [Placed DEF]
                         |
                         v
                    +---------+
                    |   E0    |  Readers & Binary Cache
                    +---------+
                     /   |   \
        +-----------+    |    +-----------+
        v                v                v
   +---------+      +---------+      +---------+
   |   E1    |      |   E2    | ---> |   E3    |
   |Congest. | <--- |Placement|      |   STA   |
   +---------+      +---------+      +---------+
```

- **E0 (Readers)**: Ingests netlists, LEF/DEF geometry, and cached Liberty tables into flat in-memory arrays.
- **E1 (Congestion Estimate)**: Scheduled immediately after E0 because global-routing overflow is the primary failure mode in microarchitectural exploration. Accepting an OpenROAD-placed `DEF` directly turns E1 into a standalone 1–2 second preflight check before E2 or E3 exist.
- **E2 (Global Placement + Abacus Legalizer)**: Places unplaced netlists using analytical electrostatic placement (ePlace) and snaps cells onto valid rows with an Abacus legalizer followed by local refinement, so E2 can feed E1 and E3 in a single Rust binary without containers.
- **E3 (Static Timing Analysis)**: Computes arrival, slew, and slack in Kahn topological order using NLDM tables—first with zero-wire pin capacitances, then with placement-based virtual RC estimation, and finally with extracted `SPEF`.

## 4. Core Data Structures (`grus-core`)

### 4.1 Typed Indices & String Interner (`interner.rs`)

Strings are interned during E0 file loading and never touched inside hot loops:

```rust
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
pub struct SymbolId(pub u32);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct LibCellId(pub u16);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct LibPinId(pub u16);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct LayerId(pub u8);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct MacroId(pub u16);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct MacroPinId(pub u32);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct CellId(pub u32);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct NetId(pub u32);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct PinId(pub u32);

#[derive(Copy, Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum PinDir {
    Input,
    Output,
    Inout,
    Internal,
}

#[derive(Default, Debug, Clone, Serialize, Deserialize)]
pub struct StringInterner {
    strings: Vec<String>,
    #[serde(skip)]
    map: HashMap<String, SymbolId>,
}

impl StringInterner {
    pub fn intern(&mut self, s: &str) -> SymbolId {
        if let Some(&id) = self.map.get(s) {
            return id;
        }
        let id = SymbolId(self.strings.len() as u32);
        let owned = s.to_owned();
        self.strings.push(owned.clone());
        self.map.insert(owned, id);
        id
    }

    pub fn resolve(&self, id: SymbolId) -> &str {
        &self.strings[id.0 as usize]
    }

    pub fn rebuild_map(&mut self) {
        self.map.clear();
        self.map.reserve(self.strings.len());
        for (i, s) in self.strings.iter().enumerate() {
            self.map.insert(s.clone(), SymbolId(i as u32));
        }
    }
}
```

### 4.2 Liberty Database (`lib_db.rs`)

All values in `LibDb` are normalized to **nanoseconds (`ns`)** for time and **picofarads (`pF`)** for capacitance during parsing so downstream STA code performs zero unit conversions.

```rust

    PositiveUnate,
    NegativeUnate,

    Combinational,
    CombinationalRise,
    CombinationalFall,
    RisingEdge,      // CLK -> Q (rising clock)
    FallingEdge,     // CLK -> Q (falling clock)

    HoldRising,      // D vs rising CLK
    SetupFalling,
    HoldFalling,
    Preset,
    Clear,
    RemovalRising,
    RecoveryRising,
    Other,

    InputNetTransition,
    TotalOutputNetCapacitance,

    Other,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct NldmTable {
```

### 4.3 LEF Technology & Macro Database (`tech_db.rs`)

All spatial coordinates in `TechDb` and `DesignDb` are stored in integer **DEF Database Units (`DBU`)** (in `sky130hd`, `1 micron = 1000 DBU`), with unit R/C stored in `f32` per micron.

## 5. CLI Subcommand Interface (`grus-eda`)

`crates/grus-eda/src/main.rs` exposes four subcommands corresponding to `E0`–`E3`:

```bash
# E0: Verify Liberty, LEF, DEF, and Netlist counts against OpenSTA/OpenROAD
grus-eda check-e0 \
  --lib <path.lib> \
  --tlef <path.tlef> \
  --lef <path.lef> \
  [--def <path.def>] \
  [--json <path.json> | --verilog <path.v>] \
  [--top <module_name>]

# E1: Estimate global-routing congestion directly from placed DEF
grus-eda congestion \
  --tlef <path.tlef> \
  --lef <path.lef> \
  --def <placed.def> \
  [--gcell-tracks <n>] \
  [--layer-adjust <0.0..1.0>] \
  [--heatmap]

# E2: Global placement + Abacus legalization, emitting placed DEF
grus-eda place \
  --tlef <path.tlef> \
  --lef <path.lef> \
  --def <floorplan.def> \
  --out-def <placed.def> \
  [--target-density 0.60]

# E3: Static timing analysis (zero-wire, placement-based RC, or SPEF)
grus-eda sta \
  --lib <path.lib> \
  --tlef <path.tlef> \
  --lef <path.lef> \
  --def <placed.def> \
  --sdc <path.sdc> \
  [--parasitics none | placement] \
  [--spef <path.spef>] \
  [--wire-layer <layer>]
```
