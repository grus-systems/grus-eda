# Goal

Second ticket of the multi-clock sequence (`docs/multi-clock.md`
§3): domain tagging — make eval domain-aware so a two-clock SDC
times **same-domain** paths correctly on both domains. The
`>1 design clock` bail from `mc-model` comes off inside the
eval gate; cross-domain paths and remaining unsupported forms
keep failing loudly (never silently fold).

## Work (measured spec in `docs/multi-clock.md` §1)

1. Per-port clock-net seeding: `propagate_clock` and
   `ideal_clock_parity` seed each domain from its own clock
   port (period/parity lattice per row), row-wise propagated
   flag.
2. Domain tags on launch seeds and clock pins; non-first clock
   ports excluded from data-input seeding (the probe's
   clk2-as-data-input fold goes away structurally).
3. Same-domain launch/capture pairing with **distinct
   periods** — capture required time anchored on the capture
   domain's lattice. Same-domain paths time on both domains;
   cross-domain paths (launch domain ≠ capture domain) are not
   claimed yet — count/defer with a named diagnostic
   (`mc-xdomain` owns the LCM edge-pair search; §1.2).
4. Per-domain period in MCP multipliers and latch-borrow
   windows; per-domain latency rows in I/O anchors
   (input/output clock latency keyed by the anchored clock,
   virtual rows included).
5. The `design_clock_count() > 1` gate moves: eval now accepts
   >1 design clock when every reached path is same-domain;
   still bail (named, counted) when a cross-domain launch/
   capture pair would be evaluated.
6. Golden: `sta_clocks` same-domain scenarios (`t2_int`,
   `t2_frac` same-domain rows, `t2_prop`, `t2_lat`, `t2_unc`,
   `t2_uncx` per-domain) must match the committed OpenSTA
   artifacts; keep the probe JSON as the reference source —
   golden extraction per repo rules (regenerated by a
   committed script, strict tolerances, fail-proof mutation
   on one same-domain number, then restore).
7. Record in `docs/results.md`: what now matches, what still
   bails (cross-domain pairs, `-waveform`, `set_clock_groups`,
   `-from`/`-to` uncertainty), verbatim. `docs/multi-clock.md`
   tick mc-eval. Version bump.
