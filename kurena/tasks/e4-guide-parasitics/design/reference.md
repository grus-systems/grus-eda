# e4-guide-parasitics — Reference generation

Committed per-net capacitance references for both fixtures, emitted by
the committed `generate_ref.sh` scripts in the pinned image — the same
`docker run -v $REPO:/work -v $PDK_ROOT:/pdk` re-exec pattern as step 5c.

## Shared helper: `tests/designs/guide_caps.py`

New committed python3 script (python3 exists in the pinned image; the
repo already uses it for the `*DATE` normalisation). Two modes:

```
guide_caps.py extract <spef> <out.txt>   # *D_NET name total_cap, SPEF order
guide_caps.py diff <caps_a> <caps_b>     # per-net table + stats to stdout
```

- `extract`: parse `*D_NET <name> <total>` lines; write
  `name<TAB>cap_pf` per line in file order. SPEF names keep their
  escapes verbatim (the guide caps files are compared against
  `guide_net_name` output — the same raw DEF spelling — so no unescape).
- `diff`: join the two tables on name; print per-net `name ours ref
  rel_diff`, then the summary metrics of `metrics.md` (fraction inside
  `max(5%, 1 fF)`, median/p90/max rel diff, worst-5). Nets in only one
  file are listed separately, not folded into the stats. Exit non-zero
  if the name sets are disjoint (input mixup guard), zero otherwise —
  the (b) comparison is recorded, not gated, so the script never gates
  itself.

## Step 5d in each `generate_ref.sh`

Appended after 5c in `tests/designs/gcd/generate_ref.sh` and
`tests/designs/picorv32/generate_ref.sh`; header comments updated to
list `<d>.guide.caps.txt`. `read_guides` on the **committed** `.guide`
file — so the reference SPEF provably sits on the same input the test
parses (P-GR verified `read_guides` read-back reproduces the same
per-net caps as the in-memory route).

```tcl
openroad -no_init -no_splash << 'EOF'
read_liberty /pdk/sky130A/libs.ref/sky130_fd_sc_hd/lib/sky130_fd_sc_hd__tt_025C_1v80.lib
read_lef /pdk/sky130A/libs.ref/sky130_fd_sc_hd/techlef/sky130_fd_sc_hd__nom.tlef
read_lef /pdk/sky130A/libs.ref/sky130_fd_sc_hd/lef/sky130_fd_sc_hd.lef
read_def /work/tests/designs/<d>/<d>.placed.def
read_sdc /work/tests/designs/<d>/<d>.sdc
set_wire_rc -layer met2
read_guides /work/tests/designs/<d>/<d>.guide
estimate_parasitics -global_routing -spef_file /work/tests/designs/<d>/<d>.guide.spef
exit
EOF

python3 /work/tests/designs/guide_caps.py extract \
    "${SCRIPT_DIR}/<d>.guide.spef" "${SCRIPT_DIR}/<d>.guide.caps.txt"
```

- `set_wire_rc` first (`EST-0018` otherwise) — `-layer met2` matches
  every other parasitics step in the scripts; whether the layer choice
  matters is probe question Q4 and is recorded, not assumed.
- Golden split (same precedent as `*.routed.spef`): `gcd.guide.spef`
  (~200 KB, under the 1 MB guideline) commits — it is the probe's
  evidence artifact and a ready `--spef` input for later tickets.
  `picorv32.guide.spef` (~5 MB) does not; it is regenerated by the same
  step and added to `.gitignore` alongside `picorv32.routed.spef`.
- The committed assertion input for both designs is the caps table
  (`gcd` ~270 lines; `picorv32` ~6.7 k lines, well under 1 MB) — exactly
  what criterion 3 compares, and uniform across designs.
- Determinism check per E0 lesson 1: rerun the script as committed,
  `git diff` on `gcd.guide.spef` and both caps files must be empty;
  investigate, never hand-edit.
