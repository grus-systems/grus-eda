# Reporting — the named escape attempt

## §1 `fail`-line format (landed)

`crates/grus-eda/src/main.rs` ~L2202–2225 joins
`graphs.region_escape` into a ` region_escape` suffix and
`graphs.escapes` (via a `BTreeMap<(u32,u32), &EscapeRecord>`) into
`escape=<token>` from `EscapeRecord::token()`:

```
    fail <label> <Kind>[ region_escape][ escape=<token>]
```

Token shapes (single whitespace-free token, `escape=` prefixed):

```
escape=halo                    — reached via halo (span == 0)
escape=halo(span=2)            — reached via halo + corridor
escape=corridor_bound(span=31) — refused: gap exceeds corridor_lines
escape=corridor_masked         — refused: every corridor died at the mask
escape=no_anchor               — refused: no in-region pair on any escape layer
escape=halo_empty              — no legal track in the halo on any layer
```

Every `EscapeKind` renders as one `escape=` token. `corridor_bound`'s
`span` is always a *measured* index distance — the refusal probe runs
uncapped for the record (`mechanism.md` §4), so no sentinel value can
render; `no_anchor` is the explicit "nothing to aim at" case that used
to surface as `corridor_bound(span=4294967295)`. A failed pin with an
`escapes` record always shows it; a pin with `region_escape` but no
record can only happen when the mechanism was off — print no suffix
(the flag alone remains the honest report).

Example (if a refused escape stays unrouted):

```
    fail _301_/B1 NoPath region_escape escape=corridor_masked
    fail io9      NoPath region_escape escape=no_anchor
```

## §2 Consumer updates (landed)

`tests/designs/recount_unrouted.py` (~L185–200) accepts 3–5 fields on
a `fail` line: `parts[3]` must be `region_escape` when present and
`parts[4]` must start `escape=` — no semantic join, the token is
evidence text. `no_anchor` and every other token pass the prefix
check with no parser change.

`tests/designs/check_drt_ours.sh` keep-list already keeps `fail `
lines verbatim — the suffix lands in `cli_lines` automatically; no
script change. No new top-level census line (deliberate: keeps
`cli_lines` shape and the keep-list byte-stable; escape outcomes for
*routed* pins are graph-side data asserted by tests, not emit text).
