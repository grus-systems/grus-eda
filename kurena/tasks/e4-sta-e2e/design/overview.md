# e4-sta-e2e — Overview

E4 ticket 3, the closing criterion (done-when 4 in
`kurena/tasks/next-stage-scoping/design/done-when.md`): end-to-end STA on
**our guide parasitics** vs OpenSTA on the `read_guides`-driven
`-global_routing` SPEF, per endpoint on `gcd.placed.def`/`gcd.sdc` and the
picorv32 equivalent.

## Comparison chain

- **Ours**: `grus-eda route --guide-out runs/guide-check/<d>.ours.guide` →
  `grus-eda sta --parasitics guide --guide <f> --spef-out <d>.guide.ours.spef`
  (`estimate_guide_parasitics` → `write_spef`) → our `sta --spef` — in the
  tests, `load_spef` + `spef_parasitics` + `run_sta_detail`, the same
  consumer path `--spef` uses.
- **Reference**: the committed `<d>.guide.spef` (`generate_ref.sh` step 5d:
  `read_guides <d>.guide` + `estimate_parasitics -global_routing
  -spef_file` on OpenROAD's own guide) → OpenSTA `find_timing_paths`
  endpoint dump, emitted by the committed `generate_ref.sh` scripts in the
  pinned image — never hand-written.

## Gates

- **gcd**: every endpoint's arrival and slack within `max(5 ps, 1%)` —
  E3's strict bound; slew keeps the established `GCD_SPEF` 3% cell-stage
  residual (the bound names arrival+slack; all 8 fields are recorded).
- **picorv32**: floors follow the existing `routed_spef` rows in
  `docs/status.md` — `PICORV32_SPEF`: arrival floor 6 ps, slack 40 ps,
  slew 10%, TNS 2.5%.
- No looser tolerance without a named cause (per-endpoint root cause per
  AGENTS.md §7.5): guide topology (e4-1 residual), parasitics (e4-2
  island/stub caveats), or `EST-0026` warned-pin dangling caps.

## The comparison matrix

Three OpenSTA endpoint blocks go into one new golden per design,
`<d>.guide.sta.reference.json` (schema in `reference.md`):

| block | parasitics OpenSTA ran on | what it is for |
|---|---|---|
| `guide_spef` | `<d>.guide.spef` (their guides → their guide RC) | **the gate reference** — the (a)-chain's counterpart |
| `guide_ours_spef` | `<d>.guide.ours.spef` (our guides → our RC → our `write_spef`) | engine isolation: same SPEF on both sides, so ours-vs-this is the pure STA-engine residual |
| `guide_ours_readback` | `read_guides <d>.ours.guide` → `estimate_parasitics -global_routing` (our guides → their RC, in memory) | topology isolation: `guide_ours_readback` − `guide_spef` is guide quality alone; `guide_ours_spef` − `guide_ours_readback` is our RC model vs OpenROAD's on identical guides (incl. `EST-0026` treatment) |

One ours-side run (`spef_parasitics` on `<d>.guide.ours.spef`) is compared
against each block; the two golden-vs-golden diffs complete the
decomposition with no extra ours run. The unavailable cell — our
`spef_parasitics` on `<d>.guide.spef` — stays unavailable: it bails on
island-pin nets (pre-existing reader strictness recorded in e4-2).

## Key decisions

- **Separate golden file, same shape.** `<d>.guide.sta.reference.json`
  carries the three blocks under named keys, each identical to a
  `*.sta.reference.json` mode (`wns/tns` + `endpoints[]` with the 8
  fields). This mirrors the `*.propagated.reference.json` precedent and
  leaves every existing golden byte-identical.
- **Harness is reused, not forked.** One new `Rc::GuideOursSpef` variant
  in `compare_design_files`' match (loads `<d>.guide.ours.spef` through
  `load_spef`/`spef_parasitics` — the `sta --spef` semantics) and the
  existing golden-file/golden-key parameters do the rest. No change to
  `main.rs`: `--parasitics guide --guide --spef-out` and `--spef` already
  cover the whole ours chain (e4-2 CLI record).
- **Our SPEF is generated by a committed host script.**
  `tests/designs/generate_guide_ours_spef.sh <design>` runs the literal
  chain (`route --guide-out` → `sta --parasitics guide --guide
  --spef-out`) so the artifact provably comes from the pipeline under
  test. `gcd.guide.ours.spef` commits (expected < 1 MB);
  `picorv32.guide.ours.spef` is gitignored — same split as
  `*.guide.spef`/`*.rcx.spef`.
- **Golden ordering is scripted.** `generate_ref.sh` step 9c emits all
  three blocks in three `openroad` invocations (clean parasitics state
  each, the 9b precedent). It fails loudly unless
  `generate_guide_ours_spef.sh` ran first — the script guard names the
  dependency.
- **Version bump** `0.3.10` → `0.3.11` (patch: new test/reference
  surface, no breaking change) in the test commit.
