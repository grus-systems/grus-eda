# Measurement plan — what must run inside the container and land in results.md

All reference runs inside `ghcr.io/librelane/librelane:3.0.16` via
`openroad -no_init -no_splash -exit` (Tcl files, not stdin heredocs —
AGENTS §7 rule 3: `!` is history expansion on stdin). Mount repo `/work`,
PDK `/pdk`. The committed script `generate_saif_ref.sh` produces the
committed numbers; `docs/results.md` records what it measured, against the
signal each probe actually mutated.

## P1 — field semantics (recorded, no golden)

Probe variants live in `generate_saif_ref.sh` §5, generated by mutating the
just-emitted `mb.saif` and replaying `read_saif -scope tb/dut` +
`report_power -digits 6` + `report_activity_annotation` per variant.
**Every variant must name the signal it mutates** — the rejected design
recorded `igtx` as a `y`-pin probe while `replace("(TX 0)", …, 1)` actually
hit `clk`'s line (first occurrence in file order). Mutations are anchored
on the `(<name> (T0 …) …)` line (see `fixture.md` for the helper).

Variants (renamed where the target changed):

- `tc10`: all `TC` ×10 → switching scales ×10; Combinational internal ×10;
  Sequential internal follows the SDC clock, not `clk`'s `TC`.
- `duty_a` / `duty_y`: swap `T0`/`T1` on `a` and on `y` — the two signals
  with asymmetric duty. **`clk` is no longer probed for duty**: under the
  `[10,1990]` window its `T0 == T1` (990/990), so a swap would be a no-op
  that measures nothing.
- `igtx`: `TX 0→40` + `IG 0→40` **on `y`'s line** — now matching what
  `results.md` records.
- `port`: the two `INSTANCE` `NET` blocks rewritten as `PORT` → annotation
  drops to `saif 3 / unannotated 5`, report identical (propagated
  activity).
- `noghost`: `(INSTANCE ghost …)` removed → same report, same `saif 8 /
  unannotated 0` (OpenSTA silent drop).

## P2 — hierarchy resolution (recorded)

From the same script, `read_saif -scope tb/dut` on `mb.saif` prints
`Annotated 8 pin activities.` — record N and the `saif`/`unannotated`
split, and document the measured model:

- scope-`NET` names resolve to pins/ports of that instance scope (top scope →
  top ports only; internal net names dropped silently);
- `(INSTANCE _d_)` scopes annotate `_d_`'s pins via `NET` groups;
- `PORT` groups annotate nothing in this build;
- unmatched instance scopes and signal names: silently dropped (ghost probe
  confirms no warning).

## P3 — SAIF-vs-VCD agreement (the golden)

`generate_saif_ref.sh` runs two `openroad` sessions on identical design
inputs (`mb.def`, `mb.sdc`, same lef/lib):

- `read_vcd -scope tb/dut mb.vcd` → `report_power -digits 6` (the table is
  cross-checked against the committed `mb.openroad.txt` at its 3-digit
  print resolution; emit the `power_vcd` JSON block from the same run);
- `read_saif -scope tb/dut mb.saif` → `report_power -digits 6` +
  `report_activity_annotation` → filtered stdout committed as
  `mb.saif.openroad.txt`.

The Tcl/python step then parses both tables and emits
`mb.saif.reference.json` (`power_vcd` + `power_saif`, per-group
`internal_w`/`switching_w`/`leakage_w`/`total_w` — parsed, not typed).

**Window difference, recorded**: `mb.saif` now covers `[10, 1990]`
(`DURATION 1980`) — 10 ns shorter than the VCD annotation window
`[10, 2000]` — so `clk`'s `TC 199` is odd and the golden exercises the
odd-TC split (with `T0 == T1`, the tie→rise rule yields `(100, 99)`, the
in-window truth). The results entry must state that SAIF and VCD windows
differ by exactly clk's final `#2000` fall, and the OpenSTA SAIF-vs-VCD
delta now includes that truncation on top of the annotation-path
difference — the ~0.05% figure from the `[10,2000]` run is superseded by
the re-measured value.

**Committed `mb.saif.openroad.txt` is filtered output**, not verbatim
stdout: `grep -v '^\[INFO\|^\[WARNING\|^The NOWIREEXTENSIONATPIN\|^$'`
drops banner/warning noise. The script comment and the results entry both
say so.

**If regen contradicts a recorded probe finding** (per-group numbers off
beyond print rounding, a claimed quirk absent): the committed container run
wins — emit the evidence verbatim in `results.md`, adjust reader/tolerance
to the *measured* semantics, and correct these design docs in the same
change.

**Regeneration after the `vcd2saif.py` fixes is expected byte-identical.**
Both fixes are no-ops on this input: no committed signal name ends in the
`rstrip("$end")` character set, and mb.vcd's `$timescale 1ns` emits the
same `(TIMESCALE 1 ns)` line the code hardcoded. After rerunning
`generate_saif_ref.sh` end-to-end, `git diff` on `mb.saif`,
`mb.saif.reference.json`, and `mb.saif.openroad.txt` must be empty. If any
of them changes, the results entry names what changed and why before the
commit lands — no silent regeneration (the review memo's requirement).

## P4 — results.md entry (required content)

Dated entry covering:

1. The measured field→activity mapping table (P1) and hierarchy-resolution
   model (P2), including the silent-drop and PORT-group quirks — each probe
   recorded against the signal it actually mutated (`igtx` on `y`, duty on
   `a`/`y`; `clk` duty noted as degenerate under the truncated window).
2. SAIF-vs-VCD table: per-group + total, both tools' columns where
   meaningful (OpenSTA-SAIF, OpenSTA-VCD, ours-SAIF, ours-VCD), plus the
   named window difference and the per-net `clk` one-fall delta.
3. Residual divergence with **named root causes** — Sequential switching
   ~3–4% (same residual class as the VCD path — driver-pin cap, already
   named), Combinational-leakage ~23% of a ~5e-12 W term
   (state-dependent-vs-flat), `q`-net propagation vs exact count.
4. **Note that `mb.saif.openroad.txt` is `grep -v`-filtered** stdout
   (INFO/WARNING/banner/blank dropped) — not verbatim.
5. Which parts of `generate_saif_ref.sh` were actually run (AGENTS §7
   rule 9).
6. Fail-proof check: corrupt `clk` `TC 199`→`398` in `mb.saif`, confirm the
   comparison test goes red, restore.
7. **Checks run — include the full suite**: `cargo test --workspace`
   (whole workspace, not only `-p grus-core saif`/`power`) and
   `cargo clippy --workspace --all-targets -- -D warnings`.
8. **Converter fixes + regen outcome**: one line recording the two
   `vcd2saif.py` fixes (literal `$end` suffix, parsed `$timescale`), the
   container `python3 --version` used, and whether `mb.saif` regenerated
   identically (expected) or what changed and why.
