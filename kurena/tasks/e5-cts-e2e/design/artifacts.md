# e5-cts-e2e — Ours-side artifacts

`tests/designs/generate_cts_ours.sh <design>` — new committed script,
host-side like `generate_guide_ours_spef.sh` (no container). Makes the
"regenerated from committed commands" acceptance literal.

## Script shape

Mirrors `generate_guide_ours_spef.sh`: `set -euo pipefail`, `<design>`
as `$1`, input guards on `<d>.placed.def` and `<d>.cts.sdc` (loud
missing-file errors naming `generate_ref.sh`/`generate_cts_ref.sh` as
producers), PDK guard on the three sky130 files under
`${PDK_ROOT:-$HOME/.ciel}`, then:

```bash
cd "${REPO_ROOT}"
cargo build --release -p grus-eda
GRUS="${REPO_ROOT}/target/release/grus-eda"

"${GRUS}" cts \
    --tlef "${PDK_TLEF}" --lef "${PDK_LEF}" --lib "${PDK_LIB}" \
    --def  "${D}/${DESIGN}.placed.def" \
    --sdc  "${D}/${DESIGN}.cts.sdc" \
    --def-out "${D}/${DESIGN}.cts.ours.def" \
    --report  "${D}/${DESIGN}.cts.ours.report.json"
```

The CLI arm already exists (`main.rs` `Commands::Cts`); no code change.

## Outputs and commit policy

| file | size | policy |
|---|---|---|
| `gcd.cts.ours.def` | ~80 KB (6 buffers on 75 KB placed) | **committed** (< 1 MB) |
| `gcd.cts.ours.report.json` | ~1 KB | committed |
| `picorv32.cts.ours.def` | ~1.9 MB | gitignored — add `tests/designs/picorv32/picorv32.cts.ours.def` + `.report.json` lines under the existing picorv32 block in `.gitignore` |
| `picorv32.cts.def` (reference) | ~7 MB | already gitignored; **absent in a fresh checkout** — regenerate via `generate_cts_ref.sh picorv32` for the engine-axis test |

`tests/designs/README.md` additions: a `gcd.cts.ours.*`/`generate_cts_ours.sh`
row in the gcd artifact table and a picorv32 paragraph line noting the
ours-DEF pair is gitignored and regenerated by the script. SHA-256
first-16 of `picorv32.cts.ours.def` is recorded in `docs/results.md`
(the `picorv32.cts.def` precedent).

## Known artifact caveat (named, pre-existing)

`write_def_full` drops the two `+ SPECIAL` PINS (`VPWR`/`VGND`) on
re-read — `num_pins − 2` (`docs/status.md` E5 known gaps). Our
committed `gcd.cts.ours.def` carries the same gap; the e2e path
re-parses our own emitted text so both sides of the comparison are
consistent, and the reference DEF was produced by OpenROAD's own
writer. Recorded, not fixed here.
