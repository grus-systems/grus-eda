# Test Designs

This directory contains public benchmark designs used for verification against reference EDA tools (Yosys, OpenROAD, OpenSTA).

---

## 1. Design Catalog & Provenance

### `gcd` (Greatest Common Divisor)
- **Directory**: `tests/designs/gcd/`
- **Origin**: [The-OpenROAD-Project/OpenROAD-flow-scripts](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts) (`flow/designs/src/gcd/gcd.v`)
- **License**: BSD 3-Clause License (The Regents of the University of California). See `tests/designs/gcd/gcd.v`.
- **Target PDK**: SkyWater `sky130_fd_sc_hd` (1.8 V nominal corner `tt_025C_1v80`).
- **Description**: Standard 16-bit synchronous iterative GCD accelerator with valid/ready handshake interface (`req_msg`, `req_val`, `req_rdy`, `resp_msg`, `resp_val`, `resp_rdy`). Used across E0–E3 for golden equivalence checking.

### `picorv32` (RISC-V RV32I core)
- **Directory**: `tests/designs/picorv32/`
- **Origin**: [YosysHQ/picorv32](https://github.com/YosysHQ/picorv32) (`picorv32.v`, top module `picorv32` with default parameters). Downloaded 2026-11-10 from the `main` branch (the commit hash was not recorded: the GitHub API refused the lookup); SHA-256 of the file: `0836050971b3c6cdd28ac3b1e5719a67fb645161912bef1e472e63995ceb0622`.
- **License**: ISC (Claire Xenia Wolf). See the header of `tests/designs/picorv32/picorv32.v`.
- **Target PDK**: SkyWater `sky130_fd_sc_hd`, `tt_025C_1v80`.
- **Constraints**: `picorv32.sdc`, 8.0 ns clock, 1.0 ns I/O delays, 0.15 ns input transition, 0.05 pF output load.
- **Purpose**: a design larger than `gcd` for E3 (STA); since Phase 3 it also feeds the E1 congestion-map and E2 legalized-HPWL comparisons.
- **Artifacts**: generated by `tests/designs/picorv32/generate_ref.sh` (full E1/E2/E3 step set since Phase 3 ticket 01, mirroring `aes`). Committed (under 1 MB): `picorv32.reference.json`, `picorv32.gcell_usage.txt` (per-edge usage/capacity dump on the 65% utilisation placement, step 7f), `picorv32.orient.pins.txt`. Files over 1 MB (`picorv32.synth.{v,json}`, `.floorplan.def`, `.placed.def`, `.routed.spef`, `.sta.reference.json`, `.orient.def`, `.util65.def`) are **not committed** and are git-ignored. Generate them first: start Colima (Section 4, step 1), then run `bash tests/designs/picorv32/generate_ref.sh` from the host (it starts the container itself; about 8 minutes since step 7 added routing). The picorv32 tests panic, not skip, when they are missing. `picorv32.routed.spef` is OpenROAD's placement estimate, not a routed extraction. Since step 7 (ticket 16) the script also routes the placed DEF (global + detailed routing, DRC report `picorv32.drc.rpt`, empty on the 2026-11-15 generation) and extracts `picorv32.rcx.spef` with OpenRCX, and the golden carries a fourth mode `routed_spef` (1,798 endpoints); `picorv32.routed.def` and `picorv32.rcx.spef` are likewise git-ignored (SHA-256 prefixes in `docs/results.md`, step 7 entry).

### `sta_edge` (hand-written STA edge-case fixtures)

- **Directory**: `tests/designs/sta_edge/` — not a synthesised design; each case is a minimal hand-written DEF (+ SDC, + SPEF for `resistor_loop`) compared against an OpenSTA golden emitted by the case's own `generate_ref.sh` (same LibreLane container route). Covers the three "Not scheduled" items of `docs/e3-sta.md` Section 5: SPEF resistor loops, `set_clock_uncertainty` on non-register endpoints, and non-`dlxtn` latches. All files are small and committed.

### `sta_clocks` (hand-written multi-clock probe fixture)

- **Directory**: `tests/designs/sta_clocks/` — hand-written in this repository, `sky130_fd_sc_hd` cells only. `two_clock.def` has two clock ports (`clk1`, `clk2`), each buffered into its own `dfxtp` group, with cross-domain paths in both directions; `two_clock_latch.def` puts a `dlxtn` latch on the `clk2` domain feeding a `clk2` flop (every endpoint same-domain). The `t2_*.sdc` scenario files measure OpenSTA's two-clock rules (launch/capture pairing, per-clock uncertainty/latency, delay-check anchors, clock groups, multicycle and delay checks, latch borrowing) via `probe.sh` inside the same LibreLane container; `two_clock.probe.json`, `two_clock_latch.probe.json` and `probe_*.txt` are the committed evidence (< 1 MB). Since `mc-eval` (v0.2.1) the artifacts are a regression target: `test_sta_clocks_match_opensta` compares every same-domain endpoint at STRICT tolerance and pins the `CrossDomain` deferrals. Findings live in `docs/results.md` and `docs/multi-clock.md`.

## 2. Reference Artifacts (`tests/designs/gcd/`)

All golden files are strictly under 1 MB and generated from a single canonical run inside `ghcr.io/librelane/librelane:3.0.16`:

| File | Size | Description |
|---|---|---|
| `gcd.v` | 18 KB | Original Verilog RTL source. |
| `gcd.sdc` | 234 B | Minimal benchmark timing constraints (5.0 ns period, 1.0 ns I/O delays). |
| `config.yaml` | 177 B | LibreLane design configuration. |
| `generate_ref.sh` | 11 KB | Turnkey reproduction script running inside `ghcr.io/librelane/librelane:3.0.16`. |
| `gcd.synth.v` | 30 KB | Gate-level post-synthesis Verilog (Yosys + ABC, 233 logic instances). |
| `gcd.synth.json` | 693 KB | Yosys JSON representation (`write_json`) of the exact same synthesis netlist. |
| `gcd.floorplan.def` | 71 KB | Initialized floorplan DEF: placed I/O pins, fixed tap/endcaps (151 instances), PDN stripes, logic cells unplaced. |
| `gcd.placed.def` | 75 KB | Legalized placement DEF (OpenROAD global placement + detailed placement without filler cells, 384 components). |
| `gcd.routed.spef` | 164 KB | IEEE 1481 SPEF from `estimate_parasitics -placement` on `gcd.placed.def` (step 5). **Placement estimate, not a routed extraction**, despite the name. |
| `gcd.routed.def` | 219 KB | `gcd.placed.def` after global and detailed routing (met1–met5; step 5b). |
| `gcd.rcx.spef` | 211 KB | **Routed extraction**: IEEE 1481 SPEF from OpenROAD RCX (`extract_parasitics -lef_res`) on the routed shapes in step 5b. 269 `*D_NET`s, 3,544 coupling-capacitor entries. `*DATE` is normalised, so regeneration is bit-identical. Used by the `routed_spef` mode of `gcd.sta.reference.json` (step 9b). |
| `gcd.orient.def` | 76 KB | `gcd.placed.def` with the logic cells cycled through all 8 orientations (cells may leave the die). Checks pin transforms only. |
| `gcd.orient.pins.txt` | 18 KB | OpenROAD `dbITerm::getAvgXY` of every signal instance pin in `gcd.orient.def`. |
| `gcd.util{25,45,65,78}.def` | 48 KB ea | Placed DEF fixtures at 25%, 45%, 65%, and 78% core utilization (step 7e of `generate_ref.sh`) for E1 congestion ranking verification. |
| `gcd.reference.json` | 1.5 KB | Golden counts and baseline metrics dumped by OpenSTA and OpenROAD (step 8 of `generate_ref.sh`). |

Propagated-clock variants (gcd and picorv32): `<design>.propagated.sdc` is the design's `.sdc` plus `set_clock_latency` (network + `-source`), `set_clock_transition`, `set_clock_uncertainty` and `set_propagated_clock`; `<design>.propagated.reference.json` is the OpenSTA endpoint golden under key `propagated_routed_spef` on the design's `.placed.def` + `.rcx.spef`, plus a `clock_pins` array of per-clock-pin arrival/slew (`get_property` on every `is_clock` pin of `all_registers` sequential cells — the only clock consumers in these designs, which have no clock-gate cells) asserted independently of the endpoint tolerance and cross-checked against the consumers our timing graph models. Both are regenerated by `tests/designs/generate_prop_ref.sh <design>` (same LibreLane container, no flow re-run). gcd's DEF/SPEF are committed; picorv32's are git-ignored — run `tests/designs/picorv32/generate_ref.sh` first.

## 4. How to Reproduce Reference Artifacts

1. Ensure Docker is running via Colima:
   ```bash
   mise exec docker-cli@latest colima@latest lima@latest -- colima start --memory 12 --cpu 8
   ```

2. Ensure the SkyWater `sky130A` PDK is cached in `~/.ciel/sky130A` (or set `PDK_ROOT`):
   - `.lib`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/lib/sky130_fd_sc_hd__tt_025C_1v80.lib` (12 MB, excluded from git)
   - `.tlef`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/techlef/sky130_fd_sc_hd__nom.tlef` (18 KB)
   - `.lef`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/lef/sky130_fd_sc_hd.lef` (1.3 MB, excluded from git)

3. Run the reproduction script:
   ```bash
   ./tests/designs/gcd/generate_ref.sh
   ```
   The script runs inside `ghcr.io/librelane/librelane:3.0.16` and regenerates all golden files in `tests/designs/gcd/`.
