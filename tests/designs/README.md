# Test Designs

This directory contains public benchmark designs used for verification against reference EDA tools (Yosys, OpenROAD, OpenSTA).

### `gcd` (Greatest Common Divisor)
- **Directory**: `tests/designs/gcd/`
- **Origin**: [The-OpenROAD-Project/OpenROAD-flow-scripts](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts) (`flow/designs/src/gcd/gcd.v`)

### `sta_clocks` (hand-written multi-clock probe fixture)

- **Directory**: `tests/designs/sta_clocks/` — hand-written in this repository, `sky130_fd_sc_hd` cells only. `two_clock.def` has two clock ports (`clk1`, `clk2`), each buffered into its own `dfxtp` group, with cross-domain paths in both directions; `two_clock_latch.def` puts a `dlxtn` latch on the `clk2` domain feeding a `clk2` flop (every endpoint same-domain). The `t2_*.sdc` scenario files measure OpenSTA's two-clock rules (launch/capture pairing, per-clock uncertainty/latency, delay-check anchors, clock groups, multicycle and delay checks, latch borrowing) via `probe.sh` inside the same LibreLane container; `two_clock.reference.json`, `two_clock_latch.reference.json` and `probe_*.txt` are the committed golden reference (< 1 MB). Since `mc-xdomain` (v0.2.2) `test_sta_clocks_match_opensta` compares every endpoint of every parseable scenario at STRICT tolerance — cross-domain pairs evaluate on the min-gap edge pair over the period LCM with per-direction inter-clock uncertainty, delay-check-covered endpoints anchor at the capture domain's edge 0, and `t2_mdx` adds the `get_pins` `-from` startpoint form. Since `mc-selectors` (v0.2.5): clock selectors on `-from`/`-to` (a bare name matches a clock `-name` only; a clock's source-port name resolves to the port object — a resolved-but-dead selector, `t2_selport`/`t2_selpto`), `set_clock_groups` (all modes desugar to false-path cuts), `create_clock -waveform` edge instants, plus the `t2_selmd` internal `u_fy/Q` path endpoint. The `mc-cleanups` revisions add mixed-anchor delay-rule entries (`t2_clkcor`/`t2_clkcor2` — golden endpoint fields may be `null` for a corner the SDC does not time), the no-arg `[get_clocks]` all-rows form (`t2_eclk2`), the wrapped-waveform scenarios (`t2_waverot`/`t2_wavez`, v0.2.8) and the same-anchor same-sense duplicate-rule measurement (`t2_clkdup`, v0.2.9). The `xdomain-deferrals` revision (v0.2.12) resolves the four parked `CrossDomain` corners with committed probe evidence: undeclared launches keep their edge-0 clk->Q launch (`t2_u1` ordinary checks drop — pinned as named `UndeclaredLaunch` skips; `t2_u2` delay checks evaluate), a foreign launch through a latch-D borrows the latch's own window (`t2_xlat`/`t2_xlat2` on `two_clock_latch.def`), and the pair searches bound to the measured directional window so near-incommensurate grids still evaluate (`t2_lcm` warns `STA-1010` in OpenSTA, `t2_lcm2` converges) — all 52 golden scenarios evaluate (49 `two_clock` + 3 `two_clock_latch`); `probe.sh`'s `PROBE_ONLY` list keeps the six bail-pinned forms (`t2_grpn`, `t2_wave3`, `t2_wave4`, `t2_waverev`, `t2_eclk3`, `t2_eclk4`), `MEASURE_ONLY` the five evidence scenarios (`t2_eclk`, `t2_nsfrom`, `t2_nsto`, `t2_toinv`, `t2_noclk`), and `MEASURE_XD` the `xdomain-deferrals` evidence (`t2_u3` — a `-to` delay check on an unclocked capture endpoint; `t2_lcm3`/`t2_lcm4` — the period-resolution boundary where OpenSTA's common-period search converges vs warns; plus the `-digits 5` `probe_t2_xlat2_d5.txt` rerun pinning the borrow-cap event). Findings live in `docs/results.md` and `docs/multi-clock.md`.

### `sta_exceptions` (hand-written exception/diagnostic probe fixture)

- **Directory**: `tests/designs/sta_exceptions/` — hand-written in this repository, `sky130_fd_sc_hd` cells only. `exceptions.def` is a 3-FF design (`u_ff1/D` driven by a `mux2` from `u_ff0`/`u_ff2` plus a `sel` input, `u_ff2`'s clock split onto a second buffer stage, and a second `mux2` driving output `y2`). ### `microbench` (hand-written VCD/SAIF power fixture)

- **Directory**: `tests/designs/microbench/` — hand-written in this repository. `mb.def`/`mb.sdc` is the small VCD/SAIF power design (`mb.vcd`, `mb.tcl`; `mb2.vcd`/`mb2.tcl` are the two-cycle variants): `generate_saif_ref.sh` converts `mb.vcd` to `mb.saif` via the committed `vcd2saif.py`, runs OpenROAD `report_power` on both annotations, and emits `mb.saif.reference.json` (`mb.openroad.txt`/`mb.saif.openroad.txt` are the filtered console tables). `test_saif_power_mb_matches_opensta` compares the `power_saif`/`power_vcd` tables at the N7 tolerances. `mbw.def`/`mbw.sdc` is the `when`-power fixture — a single `ebufn_1`, the library's only `internal_power` `when` shape — with `mbw.vcd`/`mbw.saif` exercising both `when` branches; `generate_when_ref.sh` emits `mbw.reference.json` and `mbw.openroad.txt`. The `mbw_*.vcd` probe set (`duty55`/`duty80`/`a0`/`a0te16`/`a1`/`quiet`/`s00`–`s11`) discriminates OpenSTA's `when` semantics; its stdout is recorded in `docs/results.md`, not committed. `test_when_power_mbw_matches_opensta` compares the `mbw` tables. `mba.def`/`mba.sdc` is the activity-propagation fixture (and/or/xor/inv cone + DFF/toggle/counter + `conb` + an undriven net); `generate_activity_ref.sh` emits `mba.activity.reference.json` and the filtered `mba.none.openroad.txt` probe transcript; the `mba_*.vcd` set annotates ports/all/partial/x-z variants for the propagation probes in `docs/results.md` (2026-11-21 entry). `cp.def` is the constant-polarity fixture — a `conb_1` feeding one input each of `and2`/`or2`/`xor2`/`buf` gates whose other input is port `a` — which `mba` cannot express (no mixed constant+toggling gate); `cp_probe.tcl` is the committed OpenROAD probe (the measured reads and `-pins`/`-global` precedence are quoted in `docs/results.md`, 2026-11-21 AP2-r3 entry) and `test_constant_cone_cp_matches_opensta` asserts the resolved per-net map verbatim. Findings live in `docs/results.md` (N7 entries).

### `repro_extreme_ceff` (extreme-slew `Ceff` regression fixture)

## 4. How to Reproduce Reference Artifacts

1. Ensure Docker is running via Colima:
   ```bash
   mise exec docker-cli@latest colima@latest lima@latest -- colima start --memory 12 --cpu 8
   ```

2. Ensure the SkyWater `sky130A` PDK is cached in `~/.ciel/sky130A` (or set `PDK_ROOT`):
   - `.lib`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/lib/sky130_fd_sc_hd__tt_025C_1v80.lib` (12 MB, excluded from git)
   - `.tlef`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/techlef/sky130_fd_sc_hd__nom.tlef` (18 KB)
   - `.lef`: `~/.ciel/sky130A/libs.ref/sky130_fd_sc_hd/lef/sky130_fd_sc_hd.lef` (1.3 MB, excluded from git)

3. Run the reproduction script:
   ```bash
   ./tests/designs/gcd/generate_ref.sh
   ```
   The script runs inside `ghcr.io/librelane/librelane:3.0.16` and regenerates all golden files in `tests/designs/gcd/`.
